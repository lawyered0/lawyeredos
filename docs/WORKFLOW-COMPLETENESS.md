## Preserved foundations

Existing instructions already cover exact identity, read-only orientation/closed
matter boundaries, focused task routing/context reuse, bounded section recovery,
supported mail/attachment review and contiguous checkpoints, transmission versus
delivery, normalized audience checks, guarded saves, preview/commit recovery,
genuine tracked changes, marked/clean rendering, proportional review modes,
source hashes, countervailing evidence and unresolved-finding readiness.
The release invokes these foundations without changing their Python behavior.

## Deliberate exclusions

The Ontario calculator, trust specialization, practice-manager/identity/courier
integrations, engagement-signature retrieval adapter, cross-provider review and
continuation over existing tracked revisions are not added. Native registration
of new workflow modules is also not added: both installers/configuration still
declare six core selections. New module frontmatter under `docs/workflow-modules/`
and this static catalog make them manual source entrypoints, not native
project-discovery evidence.

No personal paths, identities, account details, templates, examples or standing
authority are part of these contracts. Practice choices remain explicit approved
human-readable policy rather than invented machine configuration. Unsupported
tracker concepts stay in proposals or approved ordinary matter records.

## Review boundary

The source inventory covered twenty personal legal-workflow families and directly
relevant reference prose, with independent reviewers assigned distinct sections.
Only neutral generic behavior was rewritten for this release. Private source
locators and examples are not included in the repository.

Initial candidate checks were editorial, identity/text review and static
file/link/catalog inspection; no project code was executed during that phase.
The separate `0.2.3 beta.1` release gate uses the existing unchanged CI/build/install
acceptance procedure. Outcomes and exact artifact evidence must be reported,
not inferred from prose coverage. No live-account, client-matter, browser or
website result is claimed. Declared interface inspection alone is not runtime
acceptance. See the [release record](RELEASE-0.2.3.md) for completed checks and the
[release plan](WORKFLOW-RELEASE-PLAN.md) for historical preparation scope.
