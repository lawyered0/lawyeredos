Here are the skills

Six jobs lawyers ask Claude to do every day.

Each skill is intentionally narrow. It tells Claude what evidence to use, where to stop, what to preview, and what still requires the lawyer’s judgment.

01

Work on a matter

lawyeredos-work-on-matter

Open one exact tracked folder, read bounded sources, explain the current position and uncertainty, and recommend a next step.

02

Matter tracker

lawyeredos-matter-tracker

Find, add, update, close, or reopen a matter through an exact preview and confirmation token.

03

Letterhead

lawyeredos-letterhead

Create a neutral branded DOCX draft and verify its metadata and rendered pages before it leaves the workspace.

04

Contract redline

lawyeredos-contract-redline

Apply already-decided edits as real Word tracked changes and produce marked and clean review copies.

05

Calendar sync

lawyeredos-calendar-sync

Plan a change to one dedicated calendar and require approval before writing. The live connector remains experimental and off by default.

06

Adversarial panel

lawyeredos-adversarial-panel

Experimentally send a bounded draft through four independent, read-only review lenses. One current-name source-fidelity lens has been runtime-accepted; the complete panel has not.

Plus one installer skill: lawyeredos-setup gathers choices, shows the deterministic setup plan, and waits for approval before any write.

From a folder of documents
to a useful next step.

Once a local folder is linked to an exact file number in the LawyeredOS register, the lawyer works through ordinary requests in Claude Code.

Fictional exampleMatter 2030-001

Supply agreement dispute · fictional local workspace

01 · What the lawyer provides

A tracked folder and the source documents

  • A matter brief describing the file
  • A source note and relevant local documents
  • An exact file number, so Claude does not guess
02 · What the lawyer types
“Open matter 2030-001. Review the matter brief and source note. Tell me the current position, what is uncertain, and one recommended next step. Do not change any files.”
03 · What actually happens
  1. Resolve. Match the register to one exact local folder.
  2. Read. Inspect only the bounded sources needed for the request.
  3. Explain. Identify the current position, uncertainty, candidate dates, and sources checked.
  4. Stop safely. Refuse ambiguity and disclose unavailable email, calendar, OCR, or other support.
04 · What the lawyer gets
Matter orientation

A concise answer in Claude Code, with limits and one recommended next step.

Internal letter draft

On request: a versioned DOCX created from the configured template and visually checked when the required rendering tools are available.

Marked and clean agreement

On request: already-decided edits applied as Word tracked changes to an editable DOCX, with verification requiring the document toolchain.

Proposed tracker update

On request: the exact next-action change shown before any register write.

Your professional review remains the control

You verify facts, governing documents, current law, and deadlines; decide legal and negotiation positions; and approve every saved or external action. LawyeredOS never sends, signs, files, serves, or changes an account on its own.

After orientation, a lawyer can ask:

  • “Draft an internal letter from these established facts. Do not send it.”
  • “Apply these decided edits to the editable agreement and produce marked and clean copies.”
  • “Preview changing the next action to ‘Review delivery clause.’”

Guided local setup

See every change
before it happens.

Download and extract LawyeredOS on a Mac, then open that folder in the Claude desktop app’s Code tab and choose Local. Paste this:

Set up LawyeredOS for me. Follow the setup instructions in this folder, ask me what you need, and check with me before changing existing files.

Claude finds the project-local setup skill, asks for the few choices it needs, and shows the deterministic installer’s exact plan before applying it. Setup never writes to user-global Claude skills, agents, or settings. It stops if a selected project skill name is already occupied by something LawyeredOS does not own. Use a brand-new empty workspace for the first fictional trial.

    Ask Claude to preview linking one existing folder to an exact file number before running the example request.

Open by design

Built to stay inspectable.

Original LawyeredOS material is designated GPL-3.0-or-later. When a public distribution channel is selected, recipients will receive the corresponding source and the rights granted by that license.

The bundled legal-redline-tools derivative retains its upstream MIT license and attribution. No source repository URL is advertised until a real publication destination exists.

The GPL governs copying, modification, and distribution. Separate safety notices add no GPL conditions: this beta is provided as-is, and every material output still requires independent verification.

Beta means bounded

What this build
does not claim.

01

No live connector acceptance yet

Gmail and dedicated Calendar adapters use fake transports in automated tests and remain experimental.

02

No OCR acceptance yet

OCRmyPDF was unavailable on the test host, so OCR remains optional and unverified there.

03

No broad host claim

The accepted target is macOS Desktop Code Local with Python 3.12. Windows and Linux remain unverified.

04

No full reviewer claim

One bounded current-name source-fidelity lens passed without tools or writes; complete four-lens orchestration remains experimental.

05

No autonomous legal authority

Jurisdiction profiles define workflow boundaries; current primary law still requires verification.

06

Not offline inference

Files are selected from a local workspace, but Claude Code may transmit relevant content under the user’s Anthropic account and settings.

07

No legal advice or relationship

LawyeredOS is software, not a lawyer or law firm. Downloading or using it provides no legal advice and creates no lawyer-client relationship with the project or maintainers.

08

Verify before acting

Claude can make material errors. Verify facts, citations, authorities, deadlines, calculations, document changes, and final work product before reliance, sending, signing, filing, or service.

09

Independent project

LawyeredOS is not affiliated with, sponsored by, or endorsed by Anthropic. Claude access, processing, retention, and privacy depend on the user’s account, plan, settings, and current provider terms.
