# Support

The public support route is not active until the repository is published.
After publication, the minimal proposed route is GitHub Issues at
`github.com/lawyered0/lawyeredos/issues` using the bundled bug or feature forms.
No response-time or support-availability commitment is made.

Before reporting a bug:

1. reproduce it with fictional data where possible;
2. run `scripts/validate_setup.py` and record only the capability names and
   pass/warn/error status;
3. record LawyeredOS, Claude Code, Python, and operating-system versions; and
4. check [TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md).

Never include client names, matter numbers, document text, email, calendar
details, credentials, token fragments, personal paths, hostnames, screenshots
of real matters, or unredacted logs. Replace them with minimal fictional data.

Security and privacy reports require the additional rules in
[SECURITY.md](SECURITY.md). Publication must not proceed until GitHub Private
vulnerability reporting is enabled and its advisory form is verified.
