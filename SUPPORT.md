# Support

Use [GitHub Issues](https://github.com/lawyered0/lawyeredos/issues) for
sanitized, reproducible bugs and bounded feature requests. Use the repository's
issue forms rather than a blank issue. No response-time or support-availability
commitment is made.

Before reporting a bug:

1. reproduce it with fictional data where possible;
2. run `scripts/validate_setup.py` and record only capability names and
   pass/warn/error status;
3. identify the host (`Claude`, `Codex`, or shared core), LawyeredOS version,
   Python version, operating system, and relevant optional-tool versions; and
4. check [TROUBLESHOOTING.md](docs/TROUBLESHOOTING.md).

Never include client names, matter numbers, document or email text, calendar
details, credentials, token fragments, account identifiers, private paths,
hostnames, confidential screenshots, or unredacted logs. Replace them with
minimal fictional data.

Security and privacy reports must use the private route in
[SECURITY.md](SECURITY.md), never a public issue.
