# Roadmap

The roadmap describes intended investigation, not promised delivery dates.

## Before the first public release

- complete user-assisted acceptance of the supported project-local Desktop Code
  discovery route using only fictional data;
- enable and verify GitHub Private vulnerability reporting and GitHub Issues;
- finish the release-tree privacy and metadata review; and
- replace private website download links with the approved repository release.

## Near-term candidates

- a managed project-local Python runtime that does not depend on retaining the
  extracted source folder;
- clearer first-matter onboarding in the wizard;
- signed checksums and a documented release build;
- clean-profile Desktop Code acceptance; and
- additional macOS/Python-version coverage.

## Experimental, not core blockers

- purpose-created Gmail read-only and dedicated Calendar acceptance;
- OCR acceptance with OCRmyPDF installed;
- Windows and Linux host evaluation; and
- a practice-manager adapter.

Live law, automatic legal deadlines, sending, filing, service, signatures, and
autonomous external actions are not roadmap shortcuts around lawyer approval.
