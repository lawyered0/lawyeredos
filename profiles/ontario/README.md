# Ontario Profile

This optional profile identifies Ontario-specific workflow boundaries. It does
not make the reusable core globally substantive law and is not a source of
current legal advice.

- Timezone default: `America/Toronto`.
- Civil procedure calculations must identify the governing Ontario rule and
  verify the current official source before reliance.
- Limitations calculations require lawyer-confirmed triggering facts and must
  account for exceptions and suspensions.
- Trust-account procedures are regulated and must remain a separate specialist
  package until their forms, sources, and licensing are independently reviewed.

The first private build does not ship a legal-deadline calculator. It preserves
the boundary that generic calendar arithmetic must not be presented as a
verified legal deadline.
